# 墨格 · Markdown 编辑器

一款功能丰富、美观实用的纯前端 Markdown 编辑器。采用「文人案头」设计：纸/墨双主题、朱砂印章点缀、稿纸底纹与古籍版式细节，支持实时预览和多种扩展功能。

## 功能特性

### 核心功能

- 实时预览 - 编辑时即时渲染 Markdown 内容
- 左右分栏布局 - 左侧编辑，右侧预览，清晰直观
- 响应式设计 - 支持桌面端和移动端，小屏幕自动切换为上下布局
- 纸/墨双主题 - 默认跟随系统深浅色偏好，一键切换并记忆
- 自动保存草稿 - 内容实时存入浏览器本地，重开页面自动恢复
- 字数统计 - 状态栏实时显示字数、行数与预计阅读时长
- 滚动同步 - 编辑区滚动时预览区跟随
- 拖拽分栏 - 拖动中缝调整「稿 / 成」比例，双击复位
- 文件导入 - 支持导入 `.md` 和 `.txt` 文件
- 文件导出 - 支持导出为 `.md` 和 `.html` 格式（HTML 随当前主题生成）
- 复制 Markdown - 导出菜单中一键复制全文
- 快捷键支持 - `Ctrl+S` 保存、`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+B` 加粗、`Ctrl+I` 斜体
- 历史记录 - 自动保存编辑历史（最多 50 步）

### 格式化工具栏

提供丰富的 Markdown 格式化工具：

- **基础格式**：粗体、斜体、删除线
- **标题**：H1、H2、H3 标题
- **链接和图片**：支持插入链接和图片
- **代码**：行内代码和代码块
- **列表**：无序列表和有序列表
- **其他**：引用、水平线、表格

### 扩展功能

- **Emoji 表情**：内置丰富的 Emoji 选择器，支持搜索功能
- **GitHub 风格提示框**：支持 5 种提示框类型
- **折叠内容**：使用 `:::details` 语法创建可折叠内容区块

## 快速开始

### 使用方法

> 可直接前往[此处](https://md.ylv.top/)体验

1. 直接用浏览器打开 `index.html` 文件
2. 在左侧编辑区输入 Markdown 内容
3. 右侧实时预览渲染效果
4. 点击工具栏按钮可快速插入 Markdown 语法

### 技术栈

- HTML5 + CSS3 + JavaScript
- [marked.js](https://marked.js.org/) - Markdown 解析器
- 无需任何后端，纯前端实现
- 零依赖，开箱即用

## 语法指南

### 基础语法

| 功能   | 语法               | 示例        |
| ---- | ---------------- | --------- |
| 粗体   | `**文本**`         | **文本**    |
| 斜体   | `*文本*`           | *文本*      |
| 删除线  | `~~文本~~`         | ~~文本~~    |
| 标题   | `# 标题`           | 一级标题      |
| 链接   | `[文本](url)`      | [链接](url) |
| 图片   | `![说明](url)`     | 图片        |
| 行内代码 | `` `代码` ``       | `代码`      |
| 代码块  | ` ``` `          | 代码块       |

| 无序列表 | `- 项目`           | 列表项       |

### 提示框

支持 GitHub 风格的 alert 语法：

```markdown
> [!NOTE]
> 这是一条提示信息
> 可以包含多行内容

> [!TIP]
> 这是一条建议提示

> [!IMPORTANT]
> 这是重要信息

> [!WARNING]
> 这是警告信息

> [!CAUTION]
> 这是注意事项
```

### 折叠内容

```markdown
:::details[可点击的标题]
这是折叠的内容，点击标题可以展开/收起
```

## 主题设计

采用「墨格」文人案头设计语言，纸/墨双主题：

- **纸（浅色）**：暖纸底 `#F6F3EC`、墨字 `#2C2A25`、朱砂强调 `#B8432C`
- **墨（深色）**：暖墨底 `#201E1B`、纸字 `#EDE8DD`、朱砂强调 `#E06B4F`
- 版式细节：顶栏与状态栏用「文武线」双线、面板标签为竖排书脊（稿 / 成）、编辑区铺稿纸底纹、空状态为双线扉页框、Toast 做成朱批便签
- 字体：标题与按钮用宋体系（Georgia / Songti / SimSun），界面用系统黑体，代码用等宽字体，全部系统字体零外链
